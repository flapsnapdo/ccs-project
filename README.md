# CCS — приложение для кофейни

iOS-приложение для сети кофеен: меню, программа лояльности и информация о точках продаж.

## Функциональность

- 📋 **Меню** — просмотр ассортимента кофейни
- 🎁 **Программа лояльности** — бонусы и скидки для постоянных клиентов
- 📍 **Точки кофейни** — информация о локациях сети

## Технологии

- Swift
- Xcode / UIKit (или SwiftUI — уточните при необходимости)
- Unit-тесты (XCTest) — папка `CSSTests`
- UI-тесты — папка `CSSUITests`

## Структура проекта

```
CSS.xcodeproj   — файл проекта Xcode
CSS             — исходный код приложения
CSSTests        — модульные тесты
CSSUITests      — UI-тесты
```

## Запуск проекта

1. Склонируйте репозиторий:
   ```
   git clone git@github.com:flapsnapdo/ccs-project.git
   ```
2. Откройте `CSS.xcodeproj` в Xcode
3. Выберите симулятор устройства и нажмите Run (⌘R)
